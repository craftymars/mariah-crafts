# ♡ Mariah Crafts OS CMS

### Private Creative Control Center

The Mariah Crafts OS Content Management System is a custom-built administrative dashboard designed to manage the public portfolio without manually editing website content in the source code.

Built with **React, Vite, and Supabase**, the CMS provides a centralized workspace for organizing projects, updating portfolio information, managing creative services, and maintaining website content.

The interface follows the same visual identity as the public portfolio, featuring retro desktop elements, pink accents, pixel-grid backgrounds, and animated floating hearts.

The CMS is intended for authorized administrators only.

## 🔐 Authentication & Security

Mariah Crafts OS uses Supabase Authentication to protect access to its private administrative dashboard.

### Administrator Access

The authentication system:

1. Checks the current authenticated user.
2. Displays the login interface when no user is signed in.
3. Verifies administrator authorization against the `admin_users` database table.
4. Grants access to the dashboard when authorization succeeds.
5. Displays an access-denied screen for unauthorized accounts.
6. Provides a sign-out option.

### Security Considerations

- Administrator authentication is handled through Supabase.
- Administrator access is checked against a dedicated database table.
- Database permissions should be enforced using Supabase Row Level Security.
- Storage access should be protected with appropriate policies.
- Private credentials and environment variables must not be committed to the repository.
- Frontend authorization checks are not a replacement for backend security policies.

The CMS is not intended to be publicly accessible to unauthorized users.

## ⚙️ Getting Started

### Prerequisites

Before running the project locally, install:

- Node.js
- npm
- Git

A configured Supabase project is required for database-backed and authentication features.

### 1. Clone the Repository

```bash
git clone https://github.com/mariah-crafts.git
```

### 2. Navigate to the Project

```bash
cd mariah-crafts
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env.local` file in the project root.

Configure the Supabase environment variables expected by your Supabase client.

For example:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_publishable_or_anon_key
```

The exact variable names must match the configuration in `src/lib/supabase.js`.

Never expose Supabase secret keys or service-role keys in frontend environment variables.

### 5. Start the Development Server

```bash
npm run dev
```

Open the local development URL displayed in your terminal.

### 6. Create a Production Build

```bash
npm run build
```

This generates the production-ready frontend build.
