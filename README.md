
# ♡ Mariah Crafts OS

### Design. Code. Create.

A creative portfolio disguised as an interactive desktop operating system.

**Mariah Crafts OS** is a custom-built digital workspace showcasing my work as a Creative Technologist, combining design, development, game creation, and interactive experiences.

Rather than building a traditional portfolio, I wanted to create something that reflects my personality, creativity, and love for technology.

---

## ✦ Features

- 🖥️ Interactive desktop-inspired dashboard
- 💗 Y2K cute-alt and pixel-inspired interface
- 🎀 Animated hearts, hover effects, and transitions
- 📁 Portfolio categories and project previews
- ⭐ Featured projects showcase
- 🎨 Creative services directory
- 👤 About Me, skills, and credentials
- 💌 Social media and contact directory
- 🕹️ Floating pixel navigation taskbar
- 📱 Responsive layout for different screen sizes

## 🎀 Design Direction

Mariah Crafts OS combines:

- Y2K-inspired digital aesthetics
- Black, electric pink, and plum colors
- Pixel-inspired typography
- Retro computer windows
- Interactive UI components
- Subtle animations and glowing accents

The goal is to create an experience that feels playful, expressive, and professional.

## ⚙️ Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

Navigate into the project:

```bash
cd YOUR_REPOSITORY
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
